# IE 计算器 V1.1.1 变更说明

- P0 输入修复：所有普通业务小数输入同时接受 `.` 和 `,`，计算前统一按点号小数解析。同一数字只允许一种小数分隔符且最多一次；非法键入或粘贴保留原合法内容。
- 增强计算器：支持逗号小数表达式，例如 `20,5×3 = 61.5`。
- CT 产能：原有 100% / 90% / 80% 三档保持不变。
- 瓶颈 CT 判断：新增 100% / 90% / 80% 三档同时展示；达标判断、TT、改善目标和差距仍以 100% 理论产能为基准。多人模式继续使用 `Σ(3600/CT_i)` 计算总理论产能。

受影响模块：生产效率、目标产量、理论人数、达成率、CT 产能、TT、线平衡、瓶颈 CT、平均值/求和、时间换算、增强计算器。
